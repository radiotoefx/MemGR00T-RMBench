# Contributions

We welcome pull requests and contributions. If you encounter issues or have
suggestions, please open an [Issue](https://github.com/radiotoefx/MemGR00T-RMBench/issues)
or submit a pull request in this repository.

## Support

MemGR00T-RMBench is an independent research preview built on the GR00T N1.7
stack. Reports should include the checkpoint identity, processor/statistics
hashes, device, and the exact command used. Please do not report the historical
pilot as evidence of task-level improvement; see [`docs/PROJECT_STATUS.md`](docs/PROJECT_STATUS.md).
